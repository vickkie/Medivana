## Verified as already OK

- `CartContext`, `WishContext`, `AuthContext` all memoize context values; persistence writes are debounced with timeout cleanup (`CartContext.jsx:25-30`, `WishContext.jsx:32-37`).
- Every Firebase `onValue` listener unsubscribes (`ChatScreen.jsx:104-121`, `ChatListScreen.jsx:65-101`, `Help.jsx:71-77`, `HelpAgentChatScreen.jsx:59-77`); expo-notifications listeners removed on unmount (`pushNotification.js:85-95`); payment polling interval cleaned up (`Checkout.jsx:111-133`).
- `useFetch` aborts in-flight requests on unmount/param change (`useFetch.js:15-19,66-68`).
- `DoctorsList` itself is well-tuned: `keyExtractor`, memoized `renderItem`, `initialNumToRender`, `getItemLayout`, `windowSize`, `onEndReached` — it's only the Home.jsx wrapper that breaks it.
- No AppState/socket.io listeners, no fetch-in-render loops found.

## Not measurable in this phase

- Cold-start wall time, re-render counts, memory footprint — needs a dev-client on device with React DevTools/Flipper.
- Bundle size breakdown — needs `npx expo export` (not run).
